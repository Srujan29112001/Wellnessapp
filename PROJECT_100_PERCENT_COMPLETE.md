## 🌟 Key Features

### 1. Life Optimization System

**Assessment Wizard** (9 steps, 10-15 minutes):
1. Basic Info (age, gender, height, weight, activity)
2. Birth Details (for astrology)
3. Personality & Constitution (chronotype, dosha)
4. Health Profile (conditions, allergies)
5. Dietary Preferences (diet, budget, cuisines)
6. Lifestyle & Work (location, occupation, schedule)
7. Sleep Preferences (duration, bedtime/wake time)
8. Goals & Priorities (primary goal, timeline, priorities 0-10)
9. Additional Preferences (IF, exercise, supplements)

**Personalized Meal Plans**:
- 3-4 meals optimized for nutrition, budget, dosha
- Ingredient-level breakdown with reasons
- Simple cooking instructions (no full recipes)
- Cost breakdown per meal
- Regenerate button for infinite variety!

**Optimized Daily Schedules**:
- Chronotype-based (early bird/night owl)
- Dosha cycle alignment (Vata/Pitta/Kapha times)
- Color-coded timeline
- Energy forecast (morning/afternoon/evening)
- Activity reasons (Ayurvedic timing)

**Holistic Wellness Scoring** (0-100):
- Physical (sleep, activity, HRV)
- Mental (EEG, focus)
- Emotional (voice, mood)
- Spiritual (practices)
- Nutritional (diet quality)
- Overall (weighted average)

```bash
# Runs on http://localhost:8000
```

### Start Frontend:
```bash
cd frontend
streamlit run app.py
# Runs on http://localhost:8501
```
